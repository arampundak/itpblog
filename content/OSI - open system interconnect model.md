The Open Systems Interconnection (OSI) model is ==a conceptual 7-layer framework created by the ISO in 1984 to standardize computer networking functions, enabling diverse systems to communicate==. It breaks communication into layers from Physical (cables/bits) to Application (user interfaces), aiding in troubleshooting and understanding network protocols.

![[ref - OSI-model-vs-TCP-IP-model.webp]]

**The 7 Layers of the OSI Model**
The layers are generally divided into "upper" (software) and "lower" (hardware) layers.

1. **[Application Layer](https://www.google.com/search?q=Application+Layer&rlz=1C5OZZY_enUS1147US1148&oq=OSI+-+open+system+interconnect+model&gs_lcrp=EgZjaHJvbWUyBggAEEUYOTIICAEQABgWGB4yCAgCEAAYFhgeMggIAxAAGBYYHjIICAQQABgWGB4yCAgFEAAYFhgeMggIBhAAGBYYHjIICAcQABgWGB4yCAgIEAAYFhgeMgoICRAAGAgYDRge0gEIMTE2NWowajSoAgOwAgHxBVOMoeJvMv04&sourceid=chrome&ie=UTF-8&mstk=AUtExfAJiq_8PAg4X4FryhpMVl9AlD6up1KLTZBoBYUBVzDO_lfcjS66E2B7lvLZNJrGr4z0_d5u8g8BEXSzdkoBiL9Xcus95S-T2EazD1Xk5VQjQicGJHw56U6OtJlY9Cm6FxzF0Vwba7Kpps3kkELfo6fjTPHa7SGCjz683eVVrlQYvyY&csui=3&ved=2ahUKEwiPn7Pk7PeTAxUDkYkEHRINGBkQgK4QegQIBBAB) (Layer 7):** Interacts directly with software applications (e.g., browsers, email clients) to provide network services.
2. **[Presentation Layer](https://www.google.com/search?q=Presentation+Layer&rlz=1C5OZZY_enUS1147US1148&oq=OSI+-+open+system+interconnect+model&gs_lcrp=EgZjaHJvbWUyBggAEEUYOTIICAEQABgWGB4yCAgCEAAYFhgeMggIAxAAGBYYHjIICAQQABgWGB4yCAgFEAAYFhgeMggIBhAAGBYYHjIICAcQABgWGB4yCAgIEAAYFhgeMgoICRAAGAgYDRge0gEIMTE2NWowajSoAgOwAgHxBVOMoeJvMv04&sourceid=chrome&ie=UTF-8&mstk=AUtExfAJiq_8PAg4X4FryhpMVl9AlD6up1KLTZBoBYUBVzDO_lfcjS66E2B7lvLZNJrGr4z0_d5u8g8BEXSzdkoBiL9Xcus95S-T2EazD1Xk5VQjQicGJHw56U6OtJlY9Cm6FxzF0Vwba7Kpps3kkELfo6fjTPHa7SGCjz683eVVrlQYvyY&csui=3&ved=2ahUKEwiPn7Pk7PeTAxUDkYkEHRINGBkQgK4QegQIBBAD) (Layer 6):** Translates, encrypts, and compresses data for the application layer, ensuring compatibility.
3. **[Session Layer](https://www.google.com/search?q=Session+Layer&rlz=1C5OZZY_enUS1147US1148&oq=OSI+-+open+system+interconnect+model&gs_lcrp=EgZjaHJvbWUyBggAEEUYOTIICAEQABgWGB4yCAgCEAAYFhgeMggIAxAAGBYYHjIICAQQABgWGB4yCAgFEAAYFhgeMggIBhAAGBYYHjIICAcQABgWGB4yCAgIEAAYFhgeMgoICRAAGAgYDRge0gEIMTE2NWowajSoAgOwAgHxBVOMoeJvMv04&sourceid=chrome&ie=UTF-8&mstk=AUtExfAJiq_8PAg4X4FryhpMVl9AlD6up1KLTZBoBYUBVzDO_lfcjS66E2B7lvLZNJrGr4z0_d5u8g8BEXSzdkoBiL9Xcus95S-T2EazD1Xk5VQjQicGJHw56U6OtJlY9Cm6FxzF0Vwba7Kpps3kkELfo6fjTPHa7SGCjz683eVVrlQYvyY&csui=3&ved=2ahUKEwiPn7Pk7PeTAxUDkYkEHRINGBkQgK4QegQIBBAF) (Layer 5):** Manages, opens, and closes connections (sessions) between applications.
4. **[Transport Layer](https://www.google.com/search?q=Transport+Layer&rlz=1C5OZZY_enUS1147US1148&oq=OSI+-+open+system+interconnect+model&gs_lcrp=EgZjaHJvbWUyBggAEEUYOTIICAEQABgWGB4yCAgCEAAYFhgeMggIAxAAGBYYHjIICAQQABgWGB4yCAgFEAAYFhgeMggIBhAAGBYYHjIICAcQABgWGB4yCAgIEAAYFhgeMgoICRAAGAgYDRge0gEIMTE2NWowajSoAgOwAgHxBVOMoeJvMv04&sourceid=chrome&ie=UTF-8&mstk=AUtExfAJiq_8PAg4X4FryhpMVl9AlD6up1KLTZBoBYUBVzDO_lfcjS66E2B7lvLZNJrGr4z0_d5u8g8BEXSzdkoBiL9Xcus95S-T2EazD1Xk5VQjQicGJHw56U6OtJlY9Cm6FxzF0Vwba7Kpps3kkELfo6fjTPHa7SGCjz683eVVrlQYvyY&csui=3&ved=2ahUKEwiPn7Pk7PeTAxUDkYkEHRINGBkQgK4QegQIBBAH) (Layer 4):** Handles end-to-end communication, flow control, and error correction (e.g., TCP, UDP).
5. **[Network Layer](https://www.google.com/search?q=Network+Layer&rlz=1C5OZZY_enUS1147US1148&oq=OSI+-+open+system+interconnect+model&gs_lcrp=EgZjaHJvbWUyBggAEEUYOTIICAEQABgWGB4yCAgCEAAYFhgeMggIAxAAGBYYHjIICAQQABgWGB4yCAgFEAAYFhgeMggIBhAAGBYYHjIICAcQABgWGB4yCAgIEAAYFhgeMgoICRAAGAgYDRge0gEIMTE2NWowajSoAgOwAgHxBVOMoeJvMv04&sourceid=chrome&ie=UTF-8&mstk=AUtExfAJiq_8PAg4X4FryhpMVl9AlD6up1KLTZBoBYUBVzDO_lfcjS66E2B7lvLZNJrGr4z0_d5u8g8BEXSzdkoBiL9Xcus95S-T2EazD1Xk5VQjQicGJHw56U6OtJlY9Cm6FxzF0Vwba7Kpps3kkELfo6fjTPHa7SGCjz683eVVrlQYvyY&csui=3&ved=2ahUKEwiPn7Pk7PeTAxUDkYkEHRINGBkQgK4QegQIBBAJ) (Layer 3):** Routes data packets across different networks; determines the best path (e.g., IP addressing).
6. **[Data Link Layer](https://www.google.com/search?q=Data+Link+Layer&rlz=1C5OZZY_enUS1147US1148&oq=OSI+-+open+system+interconnect+model&gs_lcrp=EgZjaHJvbWUyBggAEEUYOTIICAEQABgWGB4yCAgCEAAYFhgeMggIAxAAGBYYHjIICAQQABgWGB4yCAgFEAAYFhgeMggIBhAAGBYYHjIICAcQABgWGB4yCAgIEAAYFhgeMgoICRAAGAgYDRge0gEIMTE2NWowajSoAgOwAgHxBVOMoeJvMv04&sourceid=chrome&ie=UTF-8&mstk=AUtExfAJiq_8PAg4X4FryhpMVl9AlD6up1KLTZBoBYUBVzDO_lfcjS66E2B7lvLZNJrGr4z0_d5u8g8BEXSzdkoBiL9Xcus95S-T2EazD1Xk5VQjQicGJHw56U6OtJlY9Cm6FxzF0Vwba7Kpps3kkELfo6fjTPHa7SGCjz683eVVrlQYvyY&csui=3&ved=2ahUKEwiPn7Pk7PeTAxUDkYkEHRINGBkQgK4QegQIBBAL) (Layer 2):** Organizes bits into frames; handles node-to-node data transfer and error checking.
7. **[Physical Layer](https://www.google.com/search?q=Physical+Layer&rlz=1C5OZZY_enUS1147US1148&oq=OSI+-+open+system+interconnect+model&gs_lcrp=EgZjaHJvbWUyBggAEEUYOTIICAEQABgWGB4yCAgCEAAYFhgeMggIAxAAGBYYHjIICAQQABgWGB4yCAgFEAAYFhgeMggIBhAAGBYYHjIICAcQABgWGB4yCAgIEAAYFhgeMgoICRAAGAgYDRge0gEIMTE2NWowajSoAgOwAgHxBVOMoeJvMv04&sourceid=chrome&ie=UTF-8&mstk=AUtExfAJiq_8PAg4X4FryhpMVl9AlD6up1KLTZBoBYUBVzDO_lfcjS66E2B7lvLZNJrGr4z0_d5u8g8BEXSzdkoBiL9Xcus95S-T2EazD1Xk5VQjQicGJHw56U6OtJlY9Cm6FxzF0Vwba7Kpps3kkELfo6fjTPHa7SGCjz683eVVrlQYvyY&csui=3&ved=2ahUKEwiPn7Pk7PeTAxUDkYkEHRINGBkQgK4QegQIBBAN) (Layer 1):** Transmits raw, unstructured data bits over physical, electrical, or wireless media.
