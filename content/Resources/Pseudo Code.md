#software 

Tips:
Start with the main idea and goal  
Focus on what the design does rather than how.

Work towards towards the specific  
If you’re not sure how to code something, keep working  
with the pseudocode until you are more sure…or at least  
know the questions to research.

Use easy-to-read language  
It’s easier to replace more precise language with code.

Document assumptions as you make them  
Pseudocode can make high-level mistakes or misunderstandings more obvious than programming-language code.
  
After you’ve written it, review it  
Easy to understand?  
Can you follow the path of the code mentally?  
Any mistakes?  
Can you explain it to someone else?

Don’t settle for the first design  
Try a few ideas and pick the best approach  
before writing code!
