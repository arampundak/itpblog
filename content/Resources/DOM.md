The DOM (Document Object Model) is a live tree representation of your HTML that JavaScript - and therefore your device - can read from and write to. **Where sensor data becomes visible and controllable**.
- **HTML** → static description
- **DOM** → _live, mutable structure_

**DOM as a “device dashboard”**

In Connected Devices, the DOM acts as:
- a monitor (sensor values)
- a control panel (sliders, buttons)
- a debugging interface
- a human-readable log

Your Arduino doesn’t know about HTML.  
Your browser doesn’t know about sensors.

The DOM is the **meeting point**.
