File Transfer Protocol (FTP) is a standard network protocol used to transfer computer files between a client and server on a computer network. It is primarily used for uploading, downloading, and managing files on a remote server, such as updating websites, transferring large data sets, or sharing files between computers.

How FTP Works

FTP operates on a client-server model and relies on a TCP/IP network, typically employing two separate channels to handle data transfer: 
- **Control Connection (Port 21):** Handles commands from the user, such as connection requests, login, and commands to change directories or transfer files.
- **Data Connection (Port 20):** Handles the actual transfer of data, such as file uploads and downloads. 

The process involves establishing a connection, logging in with a username and password (or anonymously), and using commands to move files before closing the session.
