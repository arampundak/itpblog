## Epilog Laser Cutter General Procedures

#### Laser Material Storage
- Larger materials that do not fit in red bins are prioritized. If it is too large and does not fit on the shelf or sticks out too much, it must be stored in oversized storage in the basement.
- Periodically go through the storage cart, reduce clutter, use your best judgement. If 
- If the label does not list the current semester, email the student to inform them to update the label, if they do not update, the material will be removed and donated to community use.
- If the material is small enough to fit in a red bin, remove it from the cart and place it in the white bin hanging on the side. Email the student to inform them to pick up and store their own material. (unless the student has written approval from Phil or Ian to store on the shelf)

#### Check the Material:

Material must be checked by a shop staff member to ensure that it is approved before putting it into the machine.

- Material size limits
- Epilog Helix Mini: 12” x 24”
- Epilog Fusion Pro: 32” x 20”
- Approved material matters:
- Paper:
- Acetate sheets, vinyl, and lighting gels are not paper and not allowed in the laser cutter
- Cardboard: 
- Only single layer cardboard is allowed. 
- Our lasers are not set up for double layer cardboard and will cause a fire
- If the material is folded or bowing, warn the student about potential focusing issues
- Wood: 
- if it is thin ply wood, check if there are dark brown lines between the layers of ply. These lines are the adhesive that glue the layers together. Dark lines mean that the plywood was made with industrial glue which will burn and generate toxic fumes.
- Solid woods should be checked by Phil or Ian.
- It is common for wood to be bowed and warped, so warn the student about potential focusing issues. If the material is too warped (if it has 2 times the deflection of the material thickness, it is NOT APPROVED.)
- Acrylic: 
- make sure that the student has acrylic and not polycarbonate. If the acrylic was purchased from Canal Plastics, it is most certainly good to go into the laser cutter. Not sure what the student has? Check the FAQ below.
    

#### Check the Illustrator File:

Reviewing the student file prior to using the lasers will reduce the time spent at the machines.
- Review the tutorial on the shop site. See below for specific links per machine.
- Remind the student to start their design file with the downloadable template from the shop tutorial for the right file set up.
- Basic file check
- Make sure the artboard size matches the material limit size, this will ensure that the design file aligns properly with the “print area”
- To cut: shapes and paths should have No Fill, Stroke weight is 0.01 for in RGB red. If the student started with the template file, RGB red should already be set up in the palette.**
