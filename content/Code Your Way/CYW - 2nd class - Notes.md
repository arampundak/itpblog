Code Tracing
Read to understand the code ==before== you run it. Flow and order of line execution. Do it by hand then do it with head. Why my code is working or not working in a way.
Track variable values to see how values change at different points. console.log that sh!t to get a better understanding of what happens where.
```
console.log("x before update:", x);
...
console.log("x after update:", x);
```
