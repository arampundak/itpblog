# The Terminal
The **terminal** is a way to **talk directly to your computer’s operating system using text**.
A computer terminal is a text-based interface (like a window) that lets you send commands to the operating system to perform tasks, manage files, run programs, and automate processes, acting as a powerful tool below the graphical user interface (GUI) for developers and power users.
Most early computers only had a front panel to input or display bits and had to be connected to a terminal to print or input text through a keyboard.

You can use the terminal to access the Arduino connected to the computer - after knowing its location (/dev) in IDE. Many automation can happen through the command line - like having its readings put into a text document.  

The terminal is based on Unix OS
UNIX is:
- an operating system design philosophy (1970s)
- built for multi-user, networked machines
- designed around **small tools that do one thing well**

Shell
A shell is a program that listens to your command lines, interprets them, and asks the operating system to do things. You talk to the **shell**, and the shell talks to the OS for you. The shell **coordinates** actions
